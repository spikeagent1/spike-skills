# Repository layout

- `skills/`: approved owned and adapted source.
- `catalog/`: inventory, cohorts, and upstream provenance.
- `imports/`: pinned upstream material kept unchanged.
- `evals/reports/`: shareable summaries.
- `evals/workspaces/`: ignored generated artifacts.
- `schemas/`: catalog and evaluation schemas.
- `tools/`: deterministic audits and validators.

Do not commit credentials, memory, private conversation data, visitor identity, production checkpoints, or caches.
